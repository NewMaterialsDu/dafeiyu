大肥鱼课表

本地优先的 Android 课表应用。不注册、不上传，课表只存在你自己的手机里。

下载 APK 查看所有版本

版本 1.9.88.57 MBAndroid 7.0 及以上

它做什么

一个纯粹的课表，不多余，不打扰。

一周课表

支持单双周、非本周课程淡化显示，多张课表独立管理，每张单独配置。

从教务导入

正方、强智、URP 等常见教务，也能直接粘贴网页源码或用 Excel / CSV 导入。

上课提醒

可设提前量，重启手机后自动恢复。不需要常驻后台。

桌面小组件

周课表与当日课程两种，尺寸自适应，点一下直接进应用。

外观可调

8 套配色一键切换，格子高度、圆角、透明度、分隔线都能单独调。

完全离线

没有账号系统，没有统计 SDK，没有广告。数据只在你的手机上，卸载即清空。

下载

两个版本功能完全一致，区别只在素材与赞赏入口。

安装说明：下载后点击安装，如果提示“未知来源”，选择允许即可。 两个版本包名相同，同一台手机只能装一个——换装另一个版本时系统会提示覆盖。

支持的教务

内置常见教务类型，也支持直接粘贴网页源码，不依赖类型判断。

新正方 正方 强智 新 URP URP 强智（带节次） 网页源码导入 Excel / CSV ICS 日历

教务系统经常改版，如果导入失败，用「网页源码导入」几乎都能解决：在教务页面按 Ctrl+U 复制源码，粘贴进来即可。
